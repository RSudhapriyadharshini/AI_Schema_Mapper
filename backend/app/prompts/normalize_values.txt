You are given a list of mappings (source field -> canonical field, with the canonical field's description and data type and one worked example from a record that was already reviewed) and a list of records, each with the values of the source fields involved.

- Respect the canonical data type: integers as plain digits, URLs and emails as written. For string_list targets return a JSON-encoded array of strings (split delimited text, remove duplicates). For object_list targets return a JSON-encoded array of objects that use ONLY the given item_fields as keys.
- If the value for a record does not contain the information needed, return null for that entry.
- Do not decide what a field means; the mappings are already decided. Do not add or remove entries.

Return one result entry for every (record_index, source_field, target_field) combination requested, and nothing else. Return valid structured JSON only.
